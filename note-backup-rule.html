The 3-2-1 backup rule for small offices

Three copies, two kinds of storage, one copy somewhere else. It is simple and it works.

21 October 2026 · IT support · 1 min read

Most people only think about backups after losing files. The 3-2-1 rule gives you a plan before that happens.

The rule

  • 3 copies of important files: the original and two backups
  • 2 types of storage, for example the computer and an external drive
  • 1 copy away from the office, such as a cloud folder or a drive kept at another site

What to back up

  • Financial records and registers
  • Programme data and reports
  • Email exports and key documents
  • Software licences and setup files

Make it routine

Set a day each week for backups, or use automatic sync where possible. Name backups with the date.

Test restoring

A backup you have never opened is only a hope. Once a month, restore one file to check it works.

Protect the backups

Do not leave the external drive plugged in all the time. If a virus hits the computer, a connected drive can be damaged too.
