Ten habits for cleaning data in Excel without breaking it

Simple, repeatable steps that make messy exports safe to analyse and easy to check later.

21 October 2026 · Data and analytics · 1 min read

Most reports go wrong before any analysis starts. These habits keep your cleaning safe and repeatable.

Before you touch anything

  • Save a copy of the raw file and never edit it
  • Work on a copy named with the date and version
  • Convert the range to a table so formulas and filters follow the data

While you clean

  • Trim extra spaces and fix capitalisation so the same facility is not counted as three
  • Use a drop-down list or data validation for fields with fixed choices
  • Mark dates as real dates, not text
  • Look for duplicates before you count anything
  • Keep a column that flags rows you changed

After you clean

  • Compare totals with the raw file to be sure nothing was lost
  • Record what you changed in a short log sheet
  • Save the final version as the one source your charts and pivot tables use

Clean data is boring, and that is the goal. If your team does this every month, a dashboard becomes easy to build because the data is always in the same shape.
